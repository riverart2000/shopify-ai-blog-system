# BioLuxeLab Shopify theme safety and rollback

## Current protected themes

- Live original: `Heritage` — Shopify theme ID `198474465625`
- Redesign preview: `BioLuxeLab Modern Botanical Preview` — Shopify theme ID `203311743321`

The redesign must remain unpublished until it has been reviewed and explicitly
approved. The live Heritage theme is not modified by preview work.

## Rollback options

1. If the preview is not wanted, keep `Heritage` published and delete or ignore
   the unpublished preview theme.
2. If the redesign is published later, republish `Heritage` from Shopify Admin
   to restore the original store immediately.
3. For a file-level reset, the original downloaded Heritage source is preserved
   in Git commit `ce6cc8f`.
